Choosing a Thai OCR model by page type

OpenThai Text, OpenThai Markdown, and Typhoon OCR V2 2B on real documents for IT audit

From plain text to flowcharts

  1. Start with single-column prose

    OpenThai Text had a 0.39% character error rate and a median time of 0.31 seconds per page in the 10-page sample.

  2. Check that values stay in the right cells

    OpenThai Markdown kept all nine Do’s and nine Don’ts in their columns. Typhoon kept the left and right items paired by row.

  3. Try charts, screenshots, and flowcharts

    Check how well each model matches years to values, reads dashboard numbers in order, and follows arrows. See the three cases

  4. Pick a model for the audit task

    Start with Text for searchable prose, Markdown for multi-column content, and Typhoon with a focused prompt when you need a particular output structure.

Bank of Thailand charts
