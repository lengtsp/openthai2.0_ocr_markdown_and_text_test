เลือก OCR ภาษาไทยตามลักษณะหน้า

เทียบ OpenThai Text, OpenThai Markdown และ Typhoon OCR V2 2B จากเอกสารจริงในมุม IT Audit

ตัวอย่างโค้ด Python ทั้ง 3 โมเดล ↗

จากข้อความธรรมดาถึงผังงาน

  1. เริ่มจากข้อความคอลัมน์เดียว

    ในชุด 10 หน้า OpenThai Text อ่านผิด 0.39% และใช้เวลาค่ากลาง 0.31 วินาทีต่อหน้า บนเครื่องที่ทดสอบ

  2. ดูว่าข้อมูลยังอยู่ถูกช่องหรือไม่

    OpenThai Markdown เก็บ Do’s และ Don’ts ได้ครบฝั่งละ 9 ข้อ ส่วน Typhoon เก็บรายการซ้าย–ขวาเป็นคู่ในแต่ละแถว

  3. เพิ่มกราฟ ภาพหน้าจอ และผังงาน

    ดูว่าแต่ละรุ่นจับคู่ปี เรียงตัวเลข และตามลูกศรได้แค่ไหน ดูผลทั้ง 7 เคสตามลำดับ

  4. เลือกใช้กับงาน IT Audit

    ใช้ Text ดึงเนื้อหาไปค้น ใช้ Markdown อ่านหลายคอลัมน์ และลอง Typhoon แบบเจาะจงเมื่อต้องการรูปแบบผลลัพธ์เฉพาะ

ลองเทียบ Prompt และผล OCR ของ สกมช.
